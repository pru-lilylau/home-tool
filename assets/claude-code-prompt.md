# 俾 Claude Code 嘅 Prompt — 整 baby-recipes.html

幫我整一個 `baby-recipes.html`,呢個係我BB食譜網(由開始加固至3歲)嘅主頁面。

## 1. 視覺風格
- 顏色、字體、卡片樣式、整體排版**跟返 `recipes.html` 呢個現有檔案一致**(先讀呢個檔案攞色碼同CSS結構,唔好自己另創新風格)
- 保持品牌一致性:同一個網站,BB食譜同家常菜食譜應該睇落係同一個系列

## 2. 資料來源
- 讀取 `baby-recipes-data.js` 入面嘅 `babyRecipes` array 作為食譜資料源
- 唔好將食譜資料寫死喺HTML入面,方便日後加食譜淨係要改 `baby-recipes-data.js`

## 3. 頁面功能

### 篩選器(參考 recipes.html 現有「份量」「類型」篩選器嘅UI風格)
- **按月齡**:4-6個月 / 6-9個月 / 9-12個月 / 1-2歲 / 2-3歲
- **按分類**:水果泥 / 蔬菜泥 / 肉類 / 主食 / 湯水 / 手指食物 / 家庭餐
- **按蠶豆症安全性**(⭐呢個係我獨家賣點,UI要做得顯眼,例如用色塊/icon標示):
  - safe(綠色✓)/ caution(黃色需注意)/ avoid(紅色避免)
  - 顯示 `g6pd_note` 內容俾家長睇明點解
- **按過敏原排除**:可以揀多項排除(蛋、奶、麩質、堅果、大豆、海鮮)

### 「今日食乜好」隨機掣
- 邏輯可以參考 `recipes.html` 入面「今日食乜？」嗰個隨機功能
- 加返揀月齡先隨機嘅選項(等啱BB而家嘅階段)

### 食譜卡片
- 顯示:圖片、標題、月齡標籤、蠶豆症安全性標籤、過敏原標籤、準備時間
- 撳入去可以睇完整食材、步驟、tips

### 列印功能
- 每個食譜可以列印/儲存做PDF(方便媽媽落街市前印低)

## 4. 蠶豆症專區入口
- 首頁/頁頂加一個顯眼入口,連去日後嘅 `g6pd-guide.html`(蠶豆症飲食全攻略獨立頁,暫時得個連結掣,頁面可以之後先整)

## 5. CTA(轉化位)
- 頁面底部(參考 recipes.html 現有「想睇多啲免費家庭資源」個block風格)加一個關於幼兒保障嘅CTA,連去我嘅landing page:`https://pru-lilylau.github.io/landing-page/`
- 文案要自然,唔好太推銷,例如:「照顧BB飲食好重要,意外同疾病防唔到——想了解幼兒醫療保障可以睇呢度」

## 6. 圖片
- 圖片檔名已經喺 `baby-recipes-data.js` 嘅 `image` 欄位定好(例如 `banana-puree.jpg`)
- 圖片會放喺 `/images/baby-recipes/` 資料夾(如果你覺得路徑要改,可以自己調整,但記得話低我)
- 而家未有實際圖片檔案,可以先用placeholder,等我陸續補返啲相

## 7. 手機優先(Mobile-first)
- 大部分家長會用手機睇,篩選器同卡片排列要喺手機上都易用
